# E-Commerce Order Processing System

A core-Python (no classes, no external libraries) order processing system built as a
Python intern assessment: order validation, discounts, shipping, payment handling,
inventory updates and a sales report.

## Quick start

```
cd ecommerce_order_system
python main.py          # sales report + order details
python test_cases.py    # 62 edge-case tests
```

Python 3.8+ is required. On Mac/Linux use `python3`.

See [`ecommerce_order_system/README.md`](ecommerce_order_system/README.md) for the project
structure and business-rule assumptions.
